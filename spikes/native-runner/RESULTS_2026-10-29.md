# Native Runner spike 結果 2026-10-29

## 条件

- EKI main: `27b9029`
- Go: 1.27
- OS: Windows / `go test`、Linux / Docker `golang:1.27`
- 実行コマンド:
  - Windows: `go test ./... -count=1 -v`
  - Linux: `docker run --rm -v <checkout>:/src -w /src/spikes/native-runner golang:1.27 go test ./... -count=1`

## 観測

- 固定コマンドのstdout/stderrを取得できた。
- 終了コード7を`Result.ExitCode`へ返した。
- 出力上限5 byteで`ErrOutputCeiling`を返し、保持は5 byteだった。
- 出力し続けるコマンドを上限到達時に停止した。
- 取消し済み`context`でコマンドを開始しなかった。
- 正常終了時に出力のSHA-256を返した。
- `executor.Supervisor`経由で正常終了を`completed`、終了コード7を`failed`として観測した。
- `SandboxPolicy.Profile=container`を拒否した。
- `NetworkBytesMax=1`を拒否した。
- `SandboxPolicy.GPU`を拒否した。
- `AllowedArgs`外の引数を拒否し、許可した引数だけを実行した。
- 空の`AllowedArgs`では全引数を拒否した。
- 実行ファイルのSHA-256をストリームで計算し、一致を確認、不一致を拒否した。
- 親の環境変数を継承せず、明示した環境変数だけを子へ渡した。
- Supervisorの期限到達を`deadline_exceeded`、呼出し側の取消しを`cancelled`として観測した。
- Linuxで、期限到達時に子プロセスを含むプロセスグループを停止した。
- Windowsで、`taskkill /T`により子プロセスを含むプロセスツリーを停止した。
- WindowsとLinuxの両方で`go test`がPASSした。

## 一般化できる範囲

`executor.Runner`の最小契約である、終了コード、出力byte数、出力digest、context取消しへの追随は、固定コマンドに対して実装可能である。Supervisorの完了・失敗判定まで接続できる。

## 一般化できない範囲

- sandbox、CPU/メモリ/network/disk制限は未実装であり、未信頼Taskに使えることを示さない。
- 実行可能ファイルのdigest照合、引数許可リスト、環境変数の除去は未実装。
- `runner_stuck`後の強制停止、checkpoint、結果内容の検証は未実装。
- このspikeはArchitecture採用の根拠ではない。
