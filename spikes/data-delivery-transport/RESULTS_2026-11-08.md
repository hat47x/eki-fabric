# 2026-11-08 試験用UnixドメインソケットでのFixture送受信

## 対象と目的

Issue [#753](https://github.com/hat47x/eki-fabric/issues/753)の最初の物理的な通信検証。OSのUnixドメインソケットを使い、固定Fixtureに含まれる6つのイベントが、**実際のソケットを介して**欠落・重複・順序変更・内容の変化なく届くことを確認した。

この検証対象は[`unix_fixture_test.go`](unix_fixture_test.go)の**試験用送受信コード**であり、EKI本番のLocal IPC Adapter、既存の`WorkerPlaneService`、Lease/Grantの実認可、Connectデータ通信ではない。

## 実行記録

作業用隔離ディレクトリで次を実行した。

~~~sh
gofmt -w unix_fixture_test.go
GO111MODULE=off go test -count=1 -v
GO111MODULE=off go test -race -count=5 ./...
~~~

**観測結果**：OSのソケットを介した6件の送受信テストがPASS。内容・順序照合の負例（欠落、重複、順序変更、内容改変）4件も期待どおり拒否。race付きで5回の繰返しがPASS。

## 一般化できる範囲／できない範囲

**確認できたこと**：このOS上のUnixドメインソケットは、6つのJSONイベントを同一プロセス内の二つのgoroutine間で配送できた。受信したイベントの全件・順序・内容が送信したFixtureと一致した。また同一の照合器で4つの改変が検出された。

**確認していないこと**：別プロセス通信、EKIの本番Worker・Adapterへの組込み、Control PlaneとData Planeの分離、実Lease/FenceEpochによる認可・失効・Result Acceptance、利用側のConsumed／TEI Provider Commit、Connectでの同等性、ネットワーク障害、バックプレッシャー、性能数値。これらは`NOT RUN`。

`lease_revoked`や`result_claim`という**イベントの文字列を送受信しただけ**で、実Leaseが失効したり、実Resultが拒否されたわけではない。`TestUnixSocketFixtureWireDelivery`をEKIの実データAdapterのPASSと解釈しない。

## 追補：別プロセスUnixソケット送受信とAdapter実装面の確認

同日の初回記録では「別プロセス通信」を未実施としていたが、**その後、試験専用プログラムについて別プロセスでのUnixソケット送受信を確認**した。初回記録の確認対象（同一プロセスgoroutine間）は書き換えず、別試験の結果として追記する。

### 実際に実行した範囲

- 対象：[`unix_interprocess_test.go`](unix_interprocess_test.go)と同じGoソース（SHA-256: `3aaf3d47c70848965342bbd14cec5263183ca8643d545571349c5e8c6a3a978c`）、`fixture.json`の6イベントを含む**縮小ミラー**。正本の原byte列と完全に同一なFixtureファイルではなく、同じイベント内容を再現した。
- 環境：Linux/amd64、Go 1.23.2、`GO111MODULE=off`。Go 1.27を指定するリポジトリ本体の試験ではない。
- 仕組み：親テストプロセスがUnixドメインソケットを待ち受け、`os.Executable()`で別PIDのGoテスト子プロセスを起動。子が固定イベントをJSONとして送信し、親が全件・順序・内容を照合。読込量に上限を設け、期限を設定。
- 正常系：親と子が異なるPIDで、6イベントが一致した。**別プロセス間のソケット配送はこの限定環境でPASS**。
- 負例：子から最後の1イベントを送らない試験も実行。親は5イベントしか受け取らなかったことを検出し、全件一致とは判定しなかった。
- 実行：`GO111MODULE=off go test -count=1 -v`と`GO111MODULE=off go test -race -count=5 ./...`。正常系・欠落負例がPASS。子プロセス用ヘルパーテストは親側ではSKIP（期待どおり）。初回の未使用importによるコンパイルエラーは修正し、合格したソースのみを採用。

生ログ：[別プロセス試験](evidence/2026-11-08/unix-interprocess-test.log)／[race付き5回](evidence/2026-11-08/unix-interprocess-race.log)。

この試験は**EKI実装済みAdapterの動作試験ではない**。子プロセスは`eki-agent`ではなく同じテストバイナリで、`lease_revoked`は単なるJSONイベント、認可されたPrincipal/Leaseの有無も検証していない。`Observed Disposition`や通信性能の分位値も収集していない。
