## 実証した境界

- Proof Verification ResultをTask / Attemptへbindingできる。
- Program DigestをExecutor Admission側の期待値へbindingできる。
- Input DigestをTask Intentへbindingできる。
- Output Digestを実際のResult bytesへ再bindingできる。
- valid Proofでも未承認ProgramならRelying Partyが拒否できる。
- WorkerがVerification Resultを自己発行できない。
- Accepted Proof System / Verifier ID / Policy Revision / expiryをRelying Partyが再評価できる。
- Verifiable Computationとprivate-input / zero-knowledge requirementを分離できる。
- Execution Claim statement versionをPolicyへbindingできる。

## 重要な制限

このSpikeのMockProofはEd25519署名を使うContract Test用stand-inであり、実zkVM proofではありません。

実Proof Systemでのsoundness、prover cost、verifier cost、proof size、peak memoryは確認していません。
