## 実証した境界

- Worker self-reportとControl-observed / attested-meteringを別Assuranceとして保持できる。
- Observer IDだけを名乗っても、対応する署名鍵なしではMeasurementを偽装できない。
- ObserverごとにMaxAssuranceを固定し、payloadによるAssurance昇格を拒否できる。
- Contribution Policy側でMinimum Assuranceを要求できる。
- Metric / UnitをPolicyで明示的に許可できる。
- Accepted ResultとResource Measurementを独立して扱える。
- Policyが必要ならAccepted ResultをContribution Record発行条件にできる。
- Result EvidenceをTask / Attemptへbindingできる。
- 同一Measurementの再送は同じRecordへ収束する。
- 同一Attempt / Metricの競合Measurementをdouble countingせず拒否できる。
- Resource Class / Metric / Unit / Assuranceを保持し、Universal Scoreを生成しない。
- Contribution Authority署名付きRecordを検証できる。

## 解釈上の注意

control-observedでlease-wall-timeを120秒観測したとしても、それを120秒のGPU active timeとは呼びません。

Measurement Assuranceは、このMetricを誰がどの根拠で観測したかを示します。ResultがAcceptedであること、Contributionが外部制度で高く評価されることは別です。
