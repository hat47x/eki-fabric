# 監査の保存先を決めるときの確認表

EKI は監査を**保存しません**。記録を作り、**配備が保存します**（[ADR-0040](../../plan/adr/0040-audit-records-and-retention.md)）。この文書は、**保存先を選ぶときに何を確かめるか**を短くまとめたものです。

## 既定のままでは要件を満たさない

設定しないと、記録は**プロセスのログ**に出ます。ADR-0040 §2 が求めるのは次の3つで、**ログはどれも満たしません**。

| 求めること | ログは |
| --- | --- |
| **追記のみ**（書き換え・削除ができない） | ログの削除・ローテーションは**運用で普通に行われる** |
| **EKI のプロセスから削除できない** | **同じプロセスの権限で書いている**ので、消せる |
| **時刻は UTC で EKI の時計** | 満たせる（EKI が時刻を入れる） |

そのため、既定のまま動かすと**起動時に警告**が出ます。

```text
operator audit goes to the process log: ADR-0040 §2 asks for append-only storage the process cannot rewrite
```

**警告は「止める」ではなく「知らせる」**です。開発中は止めたくないし、**本番で気づかないまま**にはしたくない、という判断です（回収の設定漏れと同じ扱い）。

**本文の形は [spec/external/audit-records.md](../../spec/external/audit-records.md) にあります**（保存先を作る人が読む契約です）。## 選ぶときに見るもの

1. **追記のみか。** 書き換えや削除ができる保存先は、**記録として使えません**。
2. **EKI の資格情報で消せないか。** 同じ権限で消せるなら、**改ざんの検知ができません**。
3. **保持期間を表現できるか。** 取得90日・操作1年・測定30日（ADR-0040 §2）。
4. **落ちたときに何が起きるか。** 取得は続き（数を数える）、**Operator の操作は止まります**（ADR-0040 §5）。

## 監視

udit_unrecorded は**5分ごとに書き出されます**（ADR-0039）。**値が増えたらアラート**にしてください（ADR-0040 §6）。正常な配備では 0 のままで、**1 でも増えたのは異常**です。1回だけなら一時的な失敗かもしれないので、**次の書き出しでも増えていれば持続的な障害**として扱います。
