# EKI Fabric（益）

EKI Fabricは、異質で一時的な計算資源を、安全性・利用者影響・データ局所性・コストを考慮しながら、複数のソフトウェアから共通利用できる形で接続する **distributed compute fabric** を目指す実験的なOSSプロジェクトです。

現段階は**上流要件の具体化**にあります。実装方式や特定ミドルウェアを先に固定せず、利用主体・提供主体の双方が悪意を持ち得ること、善意のアドホック参加者を受け入れること、企業内利用から組織間・公益利用まで同じ基本モデルで扱えることを前提に、要件と脅威モデルを先に固めます。

## 現時点の中心仮説

- SEI Cognition、TEI、SUIなど既知のOSSだけでなく、未知のOSS・Webアプリ・他社ソフトウェアから利用できる。
- Goは有力な基準実装候補だが、EKIの利用契約をGo専用にはしない。
- 業務端末、ワークステーション、専用ノード、ブラウザ、一時参加ノード、クラウドなど、性質の異なる資源を同一視しない。
- 業務端末では人間の利用を常に優先し、資源提供は利用者が即時に停止できる。
- ClientもWorkerも信頼境界の外に置き、認証済みであっても善意を前提としない。
- Workerの結果は検証されるまで正しい結果とみなさない。
- 高価な高可用性を全計算へ一律に要求せず、再実行可能な計算では基盤全体で信頼性を得る。
- 余剰計算能力はクラウド費削減だけでなく、組織の認知資源へ還流させる。
- 組織間や公益用途ではCompute Grantを可能にし、資源提供実績を外部の任意の価値交換制度へ接続できる余地を持つ。
- EKI自身は通貨を発行せず、現金化、市場価格、交換レートを定義しない。
